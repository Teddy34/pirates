## PinyonScript-Regular.woff2

The script face of "Pirates!" in the title logo.

- **Font:** Pinyon Script, Regular. Copyright 2024 The Pinyon Project
  Authors (https://github.com/SorkinType/Pinyon).
- **Licence:** SIL Open Font License 1.1, copied in `OFL-PinyonScript.txt`.
  The font has no Reserved Font Name. It may be bundled and redistributed
  with the game as long as the licence goes with it and the font is not sold
  on its own.
- **Source:** `ofl/pinyonscript/PinyonScript-Regular.ttf` from the Google
  Fonts repository (https://github.com/google/fonts), downloaded 2026-11-15
  (latest commit touching the file: `0b47e1b0`). SHA-256 of the downloaded
  TTF: `4aab130a6ed27f8b8117738c84a5602edf9300cdcc0651a9a65bf96f451ac29a`.
- **Process:** converted to WOFF2 with `woff2_compress` (Google woff2), no
  other change.
- No material from the original game was used. The pixel "Retro" beside it
  is drawn in code (`src/title-logo.mjs`) and is original.
